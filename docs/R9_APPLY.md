# R9 — Prompt Builder: разбиение `promptbuilder_tab.py`

Архив — **наложение** на корень репозитория (после R2/R8). Удалять ничего
не нужно, команды git не нужны.

## Что было не так

`promptbuilder_tab.py` — 1112 строк и 4 класса в одном файле. Это редактор
JSON-конфига (дерево блоков, пресеты, негативы), а не построение промптов,
поэтому слои domain/application/infrastructure здесь не нужны: достаточно
разнести классы и вынести операции над деревом.

## Что изменилось

**Файлы** (`comfyui_studio/prompt_builder/`)

| Файл | Что внутри | Строк |
|---|---|---|
| `lora_table_editor.py` | `LoraTableEditor` | 110 |
| `preset_group_editor.py` | `PresetGroupEditor` (было `_PresetGroupEditor`) | 153 |
| `named_text_list_editor.py` | `NamedTextListEditor` (было `_NamedTextListEditor`) | 153 |
| `tree_ops.py` | операции над сырым деревом, **без Qt** | 132 |
| `promptbuilder_tab.py` | `PromptBuilderTab`, 1112 → 709 строк | |

- Тела трёх классов перенесены **без изменений** (сверено по AST с
  оригиналом; различаются только имена двух приватных классов, в отдельном
  модуле они стали публичными). Нигде в проекте они не импортировались.
- `tree_ops.py`: `find_owner_category`, `current_container_for_add`,
  `options_list_for_add`, `new_group_node` / `new_category_node` /
  `new_option_node`, `remove_node`, `move_node`. `PromptBuilderTab` стал
  тонкой обёрткой: Qt-часть (дерево, диалоги, перестроение, dirty-флаг)
  осталась во вкладке.
- Единственное отличие по логике: блок-владелец варианта теперь ищется по
  самим спискам словарей, а не обходом `QTreeWidget`. Дерево строится из тех
  же списков; на 3000 случайных деревьях (22 527 запросов) старый и новый
  поиск дали одинаковый результат.
- `_find_owner_category` из вкладки удалён: он был нужен только
  `_current_container_for_add`.
- Формат `prompt_builder_config.json`, тексты сообщений и порядок ключей в
  новых узлах прежние. Сборки не затронуты: все новые модули импортируются
  статически из `promptbuilder_tab.py`.
- `pyproject.toml`: `tree_ops` добавлен в строгий mypy (правило R11.3).

## Что сохранено намеренно (странности прежнего поведения)

`list.remove` и `list.index` в «Удалить» и «Выше/Ниже» ищут узел по
**равенству** словарей, а не по тождеству. Если в одном списке два
одинаковых узла (например, два варианта «Новый вариант» с пустыми тегами),
то «Выше/Ниже» для второго берёт индекс первого и порядок визуально не
меняется. Содержимое при этом не теряется. Зафиксировано тестами
`..._known_quirk` в `test_tree_ops.py`; чинить — отдельным решением, не в R9.

## Тесты

- `tests/prompt_builder/test_tree_ops.py` — 22 теста, без Qt.
- `tests/prompt_builder/test_editor_widgets.py` — 11 тестов на Qt
  (`pytest-qt`): круговой проход трёх редакторов, `load()` → `to_raw()` целой
  вкладки без изменений, кнопки «+ Блок», «+ Вариант» (включая отказы для
  группы и свободного текста), «Выше», «Удалить» (с подтверждением и без).
- Ожидание на Windows: **около 1022 passed и 68 skipped** (оценка от
  989 после R2 плюс 33 новых, не гарантия).

## Что проверить вам

1. `pytest tests/prompt_builder` — особенно `test_editor_widgets.py`: его я
   в песочнице **не запускал** (там нет PySide6), только проверил статически.
   Если что-то красное — пришлите вывод.
2. Prompt Builder из лаунчера и отдельным запуском: открыть реальный
   `prompt_builder_config.json`, ничего не менять, сохранить — файл не
   должен измениться (diff пустой).
3. Руками в дереве: `+ Группа`, `+ Блок` внутри группы, `+ Вариант`,
   «Выше/Ниже», «Удалить»; на группе «+ Вариант» должен показать сообщение.
4. Смена языка при открытой вкладке: подписи на месте.
5. Сборки `build_exe.bat core` / `full` и отдельная сборка Prompt Builder.
