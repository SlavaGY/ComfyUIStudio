# История комментариев: адресное упрощение модулей

Дата переноса: 18.10.2026.

При работе по 6.2 исторические объяснения перенесены из перечисленных ниже модулей. В исходниках оставлены текущие обязанности, инварианты, ограничения внешних API и причины защитных мер. Исполняемый AST каждого изменённого модуля сравнен с его состоянием перед этим проходом.

Это архив прежних формулировок, а не описание текущей реализации. Упоминания этапов, прежних ошибок и условий песочницы относятся к моменту написания оригинала.

## Что происходило

- Приложения объединялись в один процесс и общий namespace.
- Репозиторий и галерея переходили к SQL-фильтрации и загрузке страниц; крупные классы разделялись на группы операций.
- Монитор получал асинхронный опрос и WebSocket; исправлялись переподключение, совмещение stdout/WS и оценка неизвестного объёма заданий.
- Мерцание WebEngine устранялось отключением Native Window Occlusion.

## Контрактные тесты (6.3)

Контракт GenerationRepository сохраняет публичные имена, параметры, их порядок и значения по умолчанию. Семь приватных методов (_build_generations, _folder_like_pattern, _format_bucket_value, _like_escape, _record_metadata_history, _sql_histogram, _upsert_generation) и две внутренние SQL-константы исключаются из снимка. Внешних вызовов этих методов в приложении не обнаружено; упоминания в UI — комментарии. Аннотации проверяет mypy; формат их строкового представления не является контрактом вызова.

Публичные пути импорта остаются точками доступа. Проверки __module__, структуры MRO и запреты на добавление методов удаляются: они не защищают существующий вызов. Сценарий sync → чтение → редактирование → история → теги/отметки → экспорт/импорт → статистика → удаление сохраняется. У GalleryManager остаются проверки публичных методов и Qt-сигналов.

## Постепенная чистка

Этот проход охватывает галерею, репозиторий, монитор, HTTP/WS-клиент, точку входа и встроенный браузер. Исторические комментарии в других подсистемах переносятся при последующих изменениях соответствующих файлов; массовое удаление по ключевым словам не применяется.
