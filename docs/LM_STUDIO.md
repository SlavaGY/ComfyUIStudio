# LM Studio

## Два приложения

На главном экране доступны **LM Studio** (собственный интерфейс Studio) и
**LM Studio (оригинал)** (родное настольное приложение). Оба режима работают
внутри окна Studio, независимо от ComfyUI и RVC. Для переключения между ними
сначала остановите текущий режим. Возврат в настройки сохраняет его работу;
кнопки **Открыть** и **Остановить** находятся на главном экране.

## Собственный интерфейс Studio

Выберите **LM Studio → Запустить**. Приложение подключается к локальному серверу
LM Studio и при необходимости запускает его через установленный CLI `lms`.
Путь к CLI определяется из `~/.lmstudio/bin/lms.exe` или PATH; его также можно
указать в настройках **LM Studio**. По умолчанию сервер использует порт `1234`,
интерфейс Studio — `7864`. Оба адреса ограничены `127.0.0.1`. Если в LM Studio
включена аутентификация, заполните API-токен в настройках Studio.

В приложении доступны:

- чат с потоковыми ответами, остановкой и повторной генерацией;
- история диалогов, переименование, поиск и удаление;
- системный промпт, температура, Top P и ограничение длины ответа;
- отдельный просмотр рассуждения, копирование ответов и блоки кода;
- список локальных языковых моделей, загрузка с выбранным контекстом и выгрузка;
- общие с остальными инструментами Studio темы и язык.

Диалоги сохраняются в `lm_studio/chats.sqlite3` внутри папки данных лаунчера.
Оригинальная история LM Studio не изменяется и не импортируется. Поиск и
скачивание новых моделей доступны в оригинальном приложении.

При остановке закрывается интерфейс и освобождаются модели/сервер/экземпляр
движка, созданные этим приложением. Уже работающий до запуска сервер не
останавливается. В настольной установке LM Studio движок может работать в
созданном приложением скрытом процессе; установка отдельного llmster не нужна.

Параметры в секции `lm_studio` файла `config.json`: `cli_path`, `api_port`,
`ui_port`, `api_token`, `auto_start_server`. Токен передаётся только локальному
серверу и не попадает в браузер или командную строку процесса.

## Оригинальное приложение

В настройках Studio откройте раздел **LM Studio** и выберите установленный
`LM Studio.exe`. Стандартные каталоги установки Windows проверяются автоматически;
для переносной установки укажите файл вручную.

На главном экране выберите **LM Studio (оригинал)** рядом с кнопкой **Запустить**.
Родное окно LM Studio с его моделями, чатами и настройками встраивается внутрь
окна Studio (Windows). Запуск не требует работающего ComfyUI или RVC.
На странице LM Studio доступны **← Настройки** и **Остановить**. Возврат в
настройки оставляет LM Studio работающим; на главном экране доступны **Открыть**
и **Остановить**, включая остановку во время запуска. Полный выход из Studio
также останавливает LM Studio; сворачивание Studio в трей сохраняет его работу.

Если LM Studio уже открыт из того же исполняемого файла, Studio встраивает
существующее окно и управляет этим экземпляром. Остановка завершает его дерево
процессов; другие приложения и другие установки LM Studio не затрагиваются.

Путь хранится в `config.json`, секция `lm_studio.executable_path`.
Готовность API и загрузка модели по факту открытия оригинального окна
не определяются.
