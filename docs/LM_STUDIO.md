# LM Studio

## Этап 1: запуск оригинального приложения

В настройках Studio откройте раздел **LM Studio** и выберите установленный
`LM Studio.exe`. Стандартные каталоги установки Windows проверяются автоматически;
для переносной установки укажите файл вручную.

На главном экране выберите **LM Studio (оригинал)** рядом с кнопкой **Запустить**.
Откроется родное окно LM Studio с его моделями, чатами и настройками.
Запуск не требует работающего ComfyUI или RVC. LM Studio работает самостоятельно:
его закрывают в собственном окне, выход из Studio его не завершает. Повторный
запуск передаётся самому LM Studio с его штатной обработкой экземпляров приложения.

Путь хранится в `config.json`, секция `lm_studio.executable_path`.
На этом этапе Studio запускает приложение; готовность API и загрузка модели
по факту открытия окна не определяются.
