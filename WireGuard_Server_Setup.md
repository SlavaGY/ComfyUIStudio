# Поднимаем WireGuard-сервер на вашем ПК (Этап 9)

Ориентировочный гайд по общей документации WireGuard — сверяйтесь с
https://www.wireguard.com/quickstart/, если что-то на экране будет
называться иначе (версии клиента меняются).

## 1. Установка

Скачайте официальный клиент для Windows: https://www.wireguard.com/install/
Он умеет работать и как обычный сервер, отдельного «серверного» варианта не нужно.

## 2. Создайте туннель сервера

В приложении: **Add Tunnel → Add empty tunnel**. Оно само сгенерирует пару
ключей и подставит `PrivateKey` в `[Interface]`. Впишите ещё две строки:

```
[Interface]
PrivateKey = <уже вставлен приложением>
Address = 10.13.13.1/24
ListenPort = 51820
```

`10.13.13.0/24` — произвольная приватная подсеть только для самого
VPN-туннеля, не пересекается с обычной домашней Wi-Fi-сетью (обычно
`192.168.x.0/24`) — их не нужно путать, ниже это важно.

## 3. Ключи для телефона

Проще всего — создать в том же Windows-клиенте ещё один пустой туннель
(**Add Tunnel → Add empty tunnel**) только ради генерации пары ключей,
скопировать `PrivateKey` оттуда и потом удалить этот лишний туннель
(на ПК он не нужен, ключ уже переписан).

## 4. Добавьте телефон как пира на сервере

В конфиг туннеля сервера (шаг 2) добавьте:

```
[Peer]
PublicKey = <публичный ключ телефона>
AllowedIPs = 10.13.13.2/32
```

Если устройств будет несколько — по одному блоку `[Peer]` на каждое,
с уникальным адресом (`10.13.13.3/32` и т.д.).

## 5. Конфиг для импорта в приложение на телефоне

Это тот файл, который нужно будет импортировать через кнопку **VPN** в
приложении ComfyUI Studio:

```
[Interface]
PrivateKey = <приватный ключ телефона, см. шаг 3>
Address = 10.13.13.2/32
DNS = 10.13.13.1
IncludedApplications = com.comfyuistudio.terminal

[Peer]
PublicKey = <публичный ключ СЕРВЕРА (ПК)>
Endpoint = <ваш внешний IP или DDNS-имя>:51820
AllowedIPs = 192.168.X.0/24, 10.13.13.0/24
PersistentKeepalive = 25
```

Две вещи, которые легко упустить:

- **`IncludedApplications`** — нестандартное для обычного WireGuard поле,
  которое понимает именно Android-библиотека: ограничивает туннель
  только этим приложением, не трогая остальной трафик телефона (об этом
  был разговор про совместимость с вашим основным VPN).
- **`AllowedIPs` на телефоне — это подсеть ДОМАШНЕЙ Wi-Fi** (замените
  `192.168.X.0/24` на свою реальную — посмотреть можно командой
  `ipconfig` на ПК, строка "IPv4-адрес" в разделе Wi-Fi/Ethernet), а не
  только адрес самого VPN-туннеля. Без этого телефон сможет достучаться
  только до самого ПК по адресу `10.13.13.1`, но не до Remote API по его
  обычному LAN-адресу (`192.168.x.y:порт`, который уже сохранён в
  приложении с момента сопряжения) — и Studio придётся перенастраивать
  на новый адрес, чего мы как раз хотим избежать.

## 6. Проброс порта на роутере

UDP `51820` → внутренний IP ПК. Обычно в настройках роутера это
называется «Port Forwarding» / «Виртуальные серверы» / «NAT».

## 7. Внешний адрес

Если провайдер выдаёт динамический IP (у большинства домашних
подключений так) — понадобится DDNS: бесплатные варианты — No-IP,
DuckDNS, Cloudflare (со своим доменом). Вписываете DDNS-имя в `Endpoint`
конфига телефона вместо голого IP.

## 8. Автозапуск сервера вместе с Windows

В клиенте WireGuard: правой кнопкой по туннелю сервера → «Set as
Auto-Start» (или аналогичный пункт) — тогда VPN поднимается при
включении ПК, независимо от того, запущена ли сама ComfyUI Studio.

## 9. Проверка перед импортом в наше приложение

С любого устройства, которое сейчас НЕ на домашней Wi-Fi (например,
с мобильных данных), попробуйте подключиться штатным приложением
WireGuard с конфигом из шага 5 — если оно показывает "Connected" и
хотя бы `10.13.13.1` пингуется (можно через любое приложение
терминала/ping на телефоне), сервер настроен верно, и можно
импортировать тот же файл уже в ComfyUI Studio.

---

Когда сервер будет готов и проверен — просто напишите, и продолжим:
Android-часть (`TunnelSettingsActivity`, кнопка **VPN** в терминале) уже
готова и ждёт первого живого теста.
